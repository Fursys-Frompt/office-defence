# 캐릭터/아이템 디자인 검토 문서

## 1. 문서 목적

이 문서는 `Zombie Office Survival`의 캐릭터, 좀비, 아이템/시설 디자인을 다시 잡기 위한 기준 문서다.

중요한 변경점은 두 가지다.

1. 협동은 핵심 컨셉에서 제외한다.
2. 캐릭터 구분은 역할군이 아니라 플레이어 취향을 만족시키기 위한 장치로 정의한다.

따라서 캐릭터 디자인은 능력, 직업, 팀 조합을 암시하면 안 된다. 플레이어가 “이 외형이 마음에 든다”는 이유로 고를 수 있어야 한다.

## 2. 디자인 목표

### 핵심 인상

- 사무실 공간에서 벌어지는 캐주얼 개인 생존 액션
- 짧은 세션 안에서 점수, 콤보, 성장, 생존 압박이 느껴지는 게임
- 취향에 따라 고를 수 있는 매력적인 아바타
- 작게 보아도 자원, 좀비, 시설이 구분되는 명확한 게임 에셋

### 제외 인상

- 협동 디펜스 게임처럼 보이는 구성
- 역할군 선택 화면처럼 보이는 캐릭터 선택
- 탱커/딜러/힐러/엔지니어처럼 읽히는 아바타
- 능력 차이가 있을 것처럼 보이는 복장과 설명
- 임시 아이콘처럼 보이는 저가 에셋

## 3. 현재 디자인 문제

### 기존 에셋 문제

- 캐릭터가 단조롭고 선택 욕구가 약하다.
- 색만 바꾼 느낌이 강하다.
- 좀비 타입의 위협감과 속도감이 약하다.
- 아이템이 보상이라기보다 설명용 아이콘처럼 보인다.

### 최근 교체 에셋 문제

- 형태가 더 투박해졌다.
- 선이 무겁고 경직되어 저가 벡터 클립아트처럼 보인다.
- 캐릭터의 표정과 포즈가 매력적이지 않다.
- 구분성은 일부 좋아졌지만 상품성은 떨어졌다.
- 역할군처럼 보이는 장비 표현이 생겨 새 제품 방향과 맞지 않는다.

## 4. 캐릭터 디자인 원칙

## 4.1 아바타는 스킨이다

아바타는 능력 선택이 아니라 스킨 선택이다.

허용되는 차이:
- 헤어스타일
- 얼굴형
- 의상 스타일
- 색감
- 액세서리
- 분위기
- 캐주얼한 성격 표현

피해야 할 차이:
- 직업 장비
- 전투 역할 암시
- 회복/방어/공격 특화 암시
- 팀 기여 역할 암시
- 능력치 차이를 예상하게 만드는 복장

## 4.2 좋은 아바타 방향

| 방향 | 설명 |
| --- | --- |
| 스트리트 오피스 | 출근복과 캐주얼 패션을 섞은 생존자 스타일 |
| 컬러 무드 | 같은 규칙 안에서 색감과 분위기만 다르게 구성 |
| 개성형 헤어/표정 | 능력이 아니라 성격과 취향으로 구분 |
| 컬렉션형 스킨 | 플레이어가 여러 스킨을 모으고 싶어 하는 방향 |

## 4.3 나쁜 아바타 방향

| 방향 | 문제 |
| --- | --- |
| 보안요원형 | 탱커/전투 역할처럼 보임 |
| 의무병형 | 힐러 역할처럼 보임 |
| 엔지니어형 | 건설/지원 역할처럼 보임 |
| 리더형 | 기본 능력 우위나 팀 지휘 역할처럼 보임 |

## 5. 좀비 디자인 원칙

좀비는 플레이어 아바타와 다르게 명확한 게임 기능 차이가 필요하다. 적 타입은 역할군 문제가 아니라 전투 판독성 문제이므로 타입별 실루엣 차이를 유지한다.

| 타입 | 디자인 방향 |
| --- | --- |
| 일반 | 기본 사무실 좀비, 느린 압박감 |
| 러너 | 앞으로 기울어진 자세, 빠른 속도감 |
| 탱커 | 큰 덩치, 느린 중압감, 높은 내구도 |

좀비는 귀엽게 만들 수 있지만 너무 순해 보이면 안 된다.

## 6. 아이템/시설 디자인 원칙

아이템과 시설은 캐릭터 역할과 묶지 않고, 플레이어 개인 성장과 생존 선택을 돕는 게임 요소로 디자인한다.

### 자원

- 줍고 싶은 보상처럼 보여야 한다.
- 작은 크기에서도 색과 형태가 구분되어야 한다.
- 사무실 자원이라는 맥락이 보여야 한다.

### 시설

- 설치했을 때 맵의 상황 판단을 바꾸는 오브젝트처럼 보여야 한다.
- 팀 방어선이 아니라 개인 생존 동선을 보조하는 장치로 읽혀야 한다.
- 과도하게 역할 분담을 암시하는 디자인은 피한다.

| 항목 | 질문 | 목표 |

## 9. 권장 작업 순서

1. 현재 교체 에셋은 최종안에서 제외한다.
2. 캐릭터를 역할군이 아닌 스킨 컬렉션 관점으로 다시 기획한다.
3. 아바타 이름부터 취향형으로 바꾼다.
4. 흑백 실루엣보다 먼저 매력적인 얼굴, 비례, 포즈를 잡는다.
5. 게임 내 축소 크기 테스트를 별도로 한다.
6. 좀비와 아이템은 판독성을 우선하되 같은 스타일 규칙을 따른다.

## 10. 결론

현재 디자인 문제는 단순한 그림 품질 문제가 아니라 제품 방향과 디자인 기준이 섞여 있다는 점이다.

캐릭터는 역할을 설명하면 안 된다. 플레이어의 취향을 만족시키는 스킨이어야 한다. 협동을 배제한 제품 방향에서는 캐릭터보다 개인 생존, 성장, 점수 경쟁이 게임의 중심이며, 디자인도 이 방향을 방해하지 않아야 한다.
