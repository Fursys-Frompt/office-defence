# 07 시스템 구성도

## 전체 시스템 아키텍처
- Browser Client
  - React UI
  - HTML5 Canvas 렌더러
  - Keyboard/Mouse/Touch 입력
  - Socket.IO Client
- Node.js Server
  - Express 정적 파일 서빙
  - Socket.IO 실시간 통신
  - 메모리 기반 Room Store
  - 20Hz 서버 권위 게임 루프
- Render
  - 단일 Web Service
  - `npm run build`
  - `npm start`

## 폴더 구조
```text
client/src
  main.tsx
  styles.css
server/src
  index.ts
shared/src
  types.ts
docs/sdd
  01_...md ~ 11_...md
```

## 실행 순서
1. 클라이언트가 Socket.IO 연결
2. `joinRoom` 이벤트로 방 입장
3. 서버가 룸 상태 생성/갱신
4. 서버 틱이 게임 상태 계산
5. 서버가 `snapshot` 이벤트로 상태 브로드캐스트
6. 클라이언트가 Canvas를 다시 그림
