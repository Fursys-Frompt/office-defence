# 07 시스템 구성도

## 1. 구성 요소

```text
Browser Client
  - React UI
  - Canvas Renderer
  - Input Controller
  - Socket.IO Client

Node Server
  - Express Static Server
  - Socket.IO Gateway
  - Room Manager
  - Game Loop
  - Collision/AI/Scoring Rules

Shared Package
  - Type Definitions
  - Game Rule Constants
```

## 2. 통신 흐름

1. 클라이언트가 서버에 접속한다.
2. `joinRoom` 이벤트로 방을 생성하거나 입장한다.
3. 서버가 룸과 플레이어 상태를 생성/갱신한다.
4. 클라이언트는 Ready, 입력, 설정 변경 이벤트를 보낸다.
5. 서버는 게임 루프에서 상태를 계산한다.
6. 서버는 `snapshot`으로 현재 상태를 브로드캐스트한다.
7. 클라이언트는 스냅샷을 렌더링한다.

## 3. 제품 방향 해석

멀티 접속 구조는 유지할 수 있지만 시스템 목적은 협동 전술 구현이 아니다. 룸은 세션과 랭킹을 공유하기 위한 구조이며, 게임 결과는 플레이어 개인 단위로 산정한다.
