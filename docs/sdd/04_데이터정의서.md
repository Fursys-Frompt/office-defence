# 04 데이터 정의서

## 주요 상태
- GameSnapshot: 클라이언트에 송신되는 전체 룸 상태
- Room: 서버 메모리에만 존재하는 룸 상태
- Player: 플레이어 생존, 체력, 위치, 점수, 킬, 자원, 시설 기여도
- Zombie: 종류, 체력, 위치
- ResourceNode: 자원 종류, 위치
- Facility: 시설 종류, 소유자, 체력, 위치
- Projectile: 소유자, 위치, 속도, 남은 수명
- Wall: 맵 충돌 사각형

## 상태 단계
- lobby: 방 입장 및 Ready
- countdown: 3초 시작 대기
- playing: 생존 단계
- ended: 결과 표시

## 코드 위치
- 타입 정의: `shared/src/types.ts`
- 서버 상태 구현: `server/src/index.ts`
- 클라이언트 상태 수신: `client/src/main.tsx`
