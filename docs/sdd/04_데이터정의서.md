# 04 데이터 정의서

## 1. 주요 데이터 모델

### GameSnapshot

클라이언트에 송신되는 룸의 현재 표시 상태다.

주요 필드:
- phase
- players
- zombies
- resources
- facilities
- projectiles
- walls
- wave
- timeLeftSec
- feedbackEvents

### Room

서버 메모리에만 존재하는 세션 상태다.

주요 필드:
- roomId
- settings
- players
- zombies
- resources
- facilities
- projectiles
- walls
- phase
- wave
- timeLeftSec

### Player

개별 플레이어의 생존 및 점수 상태다.

주요 필드:
- id
- nickname
- avatarId
- position
- direction
- hp
- alive
- score
- kills
- combo
- inventory
- equipmentLevels
- ready
- host

### Avatar

현재 구현상 독립 데이터 모델은 아니며 `Player.avatarId`로 관리한다.

정책:
- `avatarId`는 외형 선택값이다.
- `avatarId`는 능력치, 점수, 장비, 시설, AI 타겟팅에 영향을 주면 안 된다.
- 아바타는 취향 만족과 플레이어 식별을 위한 값이다.

## 2. 게임 상태

- lobby: 입장 및 Ready 대기
- countdown: 시작 전 카운트다운
- playing: 게임 진행
- ended: 결과 표시

## 3. 자원 타입

- chairParts
- deskParts
- partitionMaterial
- powerModule
- medKit

## 4. 시설 타입

- partitionBarricade
- deskBarricade
- medStation
- powerAmplifier

## 5. 데이터 원칙

- DB 저장은 현재 범위에 포함하지 않는다.
- 모든 런타임 상태는 서버 메모리에서 관리한다.
- 개인 랭킹 산정은 플레이어별 점수, 킬, 생존 시간 기준으로 처리한다.
- 팀 단위 집계 데이터는 제품 핵심 데이터로 정의하지 않는다.
