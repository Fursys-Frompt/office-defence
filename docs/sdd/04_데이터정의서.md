# 04 데이터 정의서

## 1. 주요 데이터 모델

### GameSnapshot

클라이언트에 송신되는 룸의 현재 표시 상태다.

주요 필드:
- phase
- players
- zombies
- resources
- facilities
- projectiles
- walls
- wave
- timeLeftSec
- feedbackEvents

### Room

서버 메모리에만 존재하는 세션 상태다.

주요 필드:
- roomId
- settings
- players
- zombies
- resources
- facilities
- projectiles
- walls
- phase
- wave
- timeLeftSec

### Player

개별 플레이어의 생존 및 점수 상태다.

주요 필드:
- id
- nickname
- avatarId
- position
- direction
- hp
- alive
- score
- kills
- combo
- inventory
- equipmentLevels
- ready
- host

### Avatar

현재 구현상 독립 데이터 모델은 아니며 `Player.avatarId`로 관리한다.

정책:
- `avatarId`는 외형 선택값이다.
- `avatarId`는 능력치, 점수, 장비, 시설, AI 타겟팅에 영향을 주면 안 된다.
- 아바타는 취향 만족과 플레이어 식별을 위한 값이다.

## 2. 게임 상태

## 5. 데이터 원칙

- DB 저장은 현재 범위에 포함하지 않는다.
- 모든 런타임 상태는 서버 메모리에서 관리한다.
- 개인 랭킹 산정은 플레이어별 점수, 킬, 생존 시간 기준으로 처리한다.
- 팀 단위 집계 데이터는 제품 핵심 데이터로 정의하지 않는다.

## 6. 제작대/무기 제작 데이터 확장안

### CraftingStation

맵 배경 오브젝트 중 상호작용 가능한 컴퓨터 책상을 나타낸다.

주요 필드:
- id
- position
- width
- height
- interactionRadius

### WeaponType

제작 및 장착 가능한 무기 종류를 나타낸다.

1차 구현 대상:
- keyboardShotgun: 키보드 샷건
- printerCannon: 프린터 캐논
- plunger: 뚫어뻥
- corporateCardBoomerang: 법인카드 부메랑
- guardFlashlight: 경비아저씨의 손전등

### SupportEquipmentType

무기 슬롯과 별도로 작동하는 보조장비 종류를 나타낸다.

1차 구현 대상:
- robotVacuumDrone: 로봇청소기 드론
- mzKeycap: MZ의 키캡
- annualLeaveShield: 연차 신청서 방패

### WeaponSpec

무기별 전투 수치를 나타낸다.

주요 필드:
- weaponType
- damage
- range
- cooldownSec
- attackShape
- projectileCount
- knockback
- specialEffect

### SupportEquipmentSpec

보조장비별 효과 수치를 나타낸다.

주요 필드:
- supportEquipmentType
- cooldownSec
- durationSec
- radius
- damage
- specialEffect

### WeaponRecipe

무기 제작에 필요한 재료 조합을 나타낸다.

주요 필드:
- weaponType
- cost
- requiredStationType

1차 무기 제작 비용:

| 대상 | 비용 |
| --- | --- |
| keyboardShotgun | keycapSet 3, officeMotor 1 |
| printerCannon | paperBundle 3, officeMotor 1 |
| plunger | rubberPart 3 |
| corporateCardBoomerang | approvalKit 2 |
| guardFlashlight | batteryPack 2, approvalKit 1 |

### SupportEquipmentRecipe

보조장비 제작에 필요한 재료 조합을 나타낸다.

주요 필드:
- supportEquipmentType
- cost
- requiredStationType

1차 보조장비 제작 비용:

| 대상 | 비용 |
| --- | --- |
| robotVacuumDrone | officeMotor 1, batteryPack 2 |
| mzKeycap | keycapSet 2, batteryPack 1 |
| annualLeaveShield | paperBundle 2, approvalKit 1 |

### Player 확장 후보

추가 후보 필드:

- craftedWeapons

- craftedSupportEquipment

### ResourceType 확장 후보

1차 제작 재료는 플레이어가 기억하기 쉽도록 6종으로 제한한다.

- keycapSet: 키캡 세트
- paperBundle: 문서 더미
- officeMotor: 사무기기 모터
- batteryPack: 배터리팩
- rubberPart: 고무 부품
- approvalKit: 결재 키트

세부 부품명은 아이템 설명이나 이펙트 콘셉트로만 사용하고, 실제 제작 비용 데이터에는 위 6종만 사용한다. 실제 드롭 확률과 제작 비용은 플레이 테스트 후 조정할 수 있다.
