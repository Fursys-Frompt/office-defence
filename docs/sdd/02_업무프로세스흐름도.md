# 02 업무 프로세스 흐름도

## 1. 기본 흐름

1. 사용자가 웹 페이지에 접속한다.
2. 닉네임을 입력한다.
3. 취향에 맞는 아바타를 선택한다.
4. 방을 생성하거나 방 코드로 입장한다.
5. 플레이어가 Ready를 누른다.
6. 시작 조건 충족 시 3초 카운트다운이 진행된다.
7. 플레이어가 맵에 스폰된다.
8. 플레이어는 이동, 공격, 자원 수집, 시설 설치, 레벨업 강화, 제작대 무기/보조장비 제작을 반복한다.
9. 좀비 웨이브가 점점 강해진다.
10. 제한 시간 종료 또는 모든 플레이어 사망 시 결과 화면으로 이동한다.
11. 플레이어별 점수, 킬, 생존 시간을 기준으로 랭킹을 표시한다.

## 2. 플레이 중 반복 루프

```text
이동 -> 자원 발견 -> 수집 -> 레벨업 강화/시설 설치/무기 또는 보조장비 제작 판단 -> 좀비 처치 -> 콤보/점수 획득 -> 다음 위험 판단
```

### 제작대 흐름

```text
제작대 접근 -> 제작 가능 표시 -> 제작 UI 열기 -> 재료 확인 -> 무기 또는 보조장비 제작 -> 장착 상태 갱신 -> 자동 공격 흐름 유지
```

제작대 흐름은 개인 성장 선택지이며, 팀 역할 분담이나 협동 임무 흐름으로 해석하지 않는다.

## 3. 종료 조건

- 제한 시간이 종료된다.
- 모든 플레이어가 사망한다.

## 4. 예외 흐름

- 방 정원이 가득 차면 입장을 거부한다.
- 진행 중인 방에는 신규 입장을 거부한다.
- 방장이 나가면 남은 첫 플레이어가 방장이 된다.
- 플레이어 연결이 끊기면 해당 플레이어를 룸에서 제거한다.

## 5. 제품 방향 메모

여러 플레이어가 같은 방에 있어도 프로세스의 중심은 협동이 아니다. 각 플레이어는 동일한 규칙 안에서 독립적으로 생존하고 점수를 겨룬다.
