# 02 업무 프로세스 흐름도

## 전체 게임 흐름
1. 로비 입장
2. 방 생성 또는 방 코드 입장
3. 닉네임 입력
4. 방장이 최대 인원, 게임 시간, PVP 설정
5. 플레이어 Ready
6. 모든 플레이어 Ready 시 3초 카운트다운
7. 플레이어 랜덤 스폰 및 기본 장비 지급
8. 생존 단계 진행
9. 시간 종료 또는 전원 사망 시 종료
10. 랭킹 화면 출력

## 생존 단계 처리
- 입력 수집: 이동, 조준, 원거리 공격, 근접 공격, 시설 설치
- 서버 틱 처리: 이동, 충돌, 투사체, 좀비 추적, 자원 획득, 시설 효과, 점수
- 클라이언트 표시: 체력, 점수, 남은 시간, 웨이브, 랭킹 일부

## 종료 조건
- 제한 시간이 0초가 된다.
- 모든 플레이어가 사망한다.

## 예외 흐름
- 방 정원이 가득 차면 입장 거부
- 진행 중인 방에는 신규 입장 거부
- 방장이 나가면 남은 첫 플레이어가 방장 승계
