# 01 프로젝트 개요서

## 현재까지 확정된 정보
- 프로젝트명: Zombie Office Survival
- 장르: 실시간 멀티플레이 생존 액션, 점수 경쟁
- 플랫폼: 웹 브라우저, 데스크탑 및 모바일 동시 지원
- 기술 스택: React, TypeScript, HTML5 Canvas, Node.js, Express, Socket.IO
- 배포: Render
- 데이터베이스: 사용하지 않음, 메모리 기반 게임 상태
- 핵심 재미: 좀비 처치만이 아니라 공간 활용, 자원 수집, 생존, 방어 시설 구축
- 맵 테마: FURSYS Group 공간 설계 철학을 모티브로 한 미래형 스마트 오피스

## 범위
- MVP는 2명이 2~4주 내 개발 가능한 범위로 제한한다.
- 서버 권위 방식으로 룸, 플레이어, 좀비, 자원, 시설, 점수 상태를 관리한다.
- 클라이언트는 Canvas 렌더링과 입력 전송을 담당한다.
- 방 생성/입장, Ready, 카운트다운, 생존 플레이, 결과 랭킹을 포함한다.

## 제외 범위
- 계정, 영구 랭킹, DB 저장, 결제, 매치메이킹
- 고급 길찾기, 정교한 물리 엔진, 애니메이션 에셋 파이프라인
- 실제 브랜드 자산 사용 승인 절차: 사용자 확인 필요

## MVP 이후 확장 계획
- 계정/시즌 랭킹
- 맵 에디터와 오피스 레이아웃 프리셋
- 캐릭터 직무별 역할
- 방어 시설 업그레이드
- 관전 모드와 리플레이
