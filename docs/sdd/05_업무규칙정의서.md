# 05 업무 규칙 정의서

## 플레이어 규칙
- 초기 체력은 100이다.
- 사망한 플레이어는 이동, 공격, 자원 획득, 시설 설치를 할 수 없다.
- 생존 중 1초마다 1점을 얻는다.

## 공격 규칙
- 근접 공격: 데미지 20, 쿨타임 0.4초, 범위 공격
- 원거리 공격: 데미지 10, 쿨타임 0.7초, 투사체 사용
- 전력 증폭기 범위 안에서는 원거리 데미지가 증가한다.

## 점수 규칙
- 생존: 1초당 1점
- 일반 좀비 처치: 10점
- 러너 처치: 15점
- 탱커 처치: 30점
- 자원 수집: 3점
- 시설 설치: 20점
- 플레이어 처치: 40점
- 최후 생존: 50점

## PVP 규칙
- PVP OFF: 플레이어 공격 불가
- PVP ON: 플레이어 공격 가능

## 웨이브 규칙
- 30초마다 웨이브가 상승한다.
- 웨이브 상승에 따라 스폰 수, 상위 좀비 등장 확률, 이동속도가 증가한다.
