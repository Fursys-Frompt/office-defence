# 05 업무 규칙 정의서

## 1. 방과 세션

- 방 코드는 서버가 임의 생성하거나 사용자가 입력한 코드로 입장한다.
- 방 상태는 `lobby`, `countdown`, `playing`, `paused`, `ended` 중 하나이다.
- 방 생성자는 최초 호스트가 되며, 호스트가 나가면 남은 플레이어 중 한 명에게 호스트가 이전된다.
- 진행 중인 방에는 신규 입장할 수 없다.
- 빈 방은 메모리에서 삭제된다.

## 2. 방 설정

- 최대 인원은 2-8명이다.
- 난이도는 `easy`, `normal`, `hard`를 지원한다.
- 제한 시간은 60-600초 범위로 보정된다.
- 처치 목표는 10-1000 범위로 보정된다.
- PVP 플래그는 설정값으로 존재하지만 현재 제품 방향은 좀비 생존 경쟁 중심이다.

## 3. 게임 모드

| 모드 | 목표 | 종료 조건 |
| --- | --- | --- |
| 제한시간 생존 | 설정된 시간 동안 생존하며 점수를 획득한다. | 제한 시간 종료 또는 전원 쓰러짐 |
| 무제한 생존 | 가능한 오래 생존한다. | 전원 쓰러짐 |
| 좀비 처치 목표 | 개인 처치 목표를 먼저 달성한다. | 목표 달성자 발생 또는 전원 쓰러짐 |
| 물자 지키기 | 제한 시간 동안 물자 캐시를 보호한다. | 제한 시간 종료 또는 물자 캐시 파괴 |

## 4. 플레이어와 성장

- 아바타는 외형만 다르며 능력치 차이를 제공하지 않는다.
- 플레이어는 기본 체력 100으로 시작한다.
- 좀비 처치 수가 기준치에 도달하면 레벨업 선택지가 지급된다.
- 선택지는 사거리, 피해, 최대 체력, 이동 속도, 커피 회복, 안전지대 전개, 보급, 야간 이동, 자원 감지, 안전지대 보강, 마무리 일격 계열이다.
- 콤보는 짧은 시간 내 연속 처치 시 증가하며 결과 점수 경험을 강화한다.

## 5. 자원과 아이템

| 자원 | 용도 |
| --- | --- |
| 파티션 소재 | 안전지대 설치/수리, 일부 보조장비 제작 |
| 믹스커피 | 체력 회복, 일부 보조장비 제작 |
| 키캡 세트 | 키보드 샷건, MZ 키캡 제작 |
| 문서 더미 | 프린터 캐논, 방패/시설 제작 |
| 오피스 모터 | 발사형 장비와 드론 제작 |
| 배터리 팩 | 손전등, 드론, AED 제작 |
| 고무 부품 | 뚫어뻥, AED 제작 |
| 결재 키트 | 법인카드 부메랑, 손전등, 방패 제작 |

## 6. 제작과 장비

- 제작은 제작 스테이션 상호작용 반경 안에서 가능하다.
- 동일 장비를 다시 제작하면 강화 레벨이 오른다.
- 장비 최대 레벨은 5이다.
- 무기: 키보드 샷건, 프린터 캐논, 뚫어뻥, 법인카드 부메랑, 경비 손전등
- 보조장비: 로봇청소기 드론, MZ 키캡, 연차 신청서 방패, 비상 AED
- 보조장비는 장착과 활성화 흐름을 가진다.

## 7. 시설

- 안전지대는 제작대 주변에 기본 배치되며, 파티션 소재 사용 시 가까운 손상 안전지대를 우선 수리하고 없으면 플레이어 현재 위치에 설치된다.
- 안전지대 내부 플레이어는 천천히 회복하고 받는 피해가 감소한다. 좀비는 안전지대 내부로 진입하지 못하며, 외곽에서 안전지대 내구도를 공격한다.
- 책상 바리케이드와 정비 거점은 제작 재료를 소모해 설치한다.
- 정비 거점은 충돌 장애물이 아니며 회복/지원 거점 성격을 가진다.
- 물자 지키기 모드에서는 물자 캐시가 핵심 보호 대상이다.

## 8. 좀비와 웨이브

- 좀비 타입은 일반, 러너, 탱커이다.
- 러너는 빠른 이동과 돌진 패턴을 가진다.
- 탱커는 높은 체력과 장애물 압박 역할을 가진다.
- 웨이브, 난이도, 생존자 수, 최근 피해량에 따라 스폰 압박이 조정된다.
- 스폰 위치에는 짧은 경고 표시가 먼저 나타난다.
- 주야간 사이클은 90초 주기로 진행되며 야간에는 시야/위험감이 강화된다.

## 9. 점수와 결과

- 점수는 생존, 처치, 자원 수집, 시설 설치 등 플레이 행동에 따라 누적된다.
- 결과 화면은 플레이어별 점수, 처치 수, 생존 시간을 기준으로 랭킹을 보여준다.
- 결과는 텍스트와 이미지로 공유할 수 있다.

## 10. 운영상 제약

- 현재 상태는 서버 메모리에만 저장된다.
- 서버 재시작, 배포, 장애 발생 시 진행 중인 방은 복구되지 않는다.
- 룸 상태와 전투 로직은 단일 프로세스 기준으로 설계되어 수평 확장 전 별도 설계가 필요하다.
