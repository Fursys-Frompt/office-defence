# 10 테스트 케이스

## 테스트 케이스
- TC-001 새 방 생성 시 방 코드와 플레이어 ID를 받는다. 관련: FR-001
- TC-002 모든 플레이어가 Ready이면 countdown으로 전환된다. 관련: FR-003
- TC-003 countdown 종료 후 playing으로 전환되고 플레이어가 랜덤 스폰된다. 관련: FR-003
- TC-004 WASD 입력으로 플레이어 위치가 변경된다. 관련: FR-004
- TC-005 Space 입력 시 가까운 좀비가 있으면 근접 공격이 적용된다. 관련: FR-005
- TC-006 Space 입력 시 가까운 좀비가 없으면 가장 가까운 좀비 방향으로 원거리 공격이 적용된다. 관련: FR-005
- TC-007 자원 접촉 시 점수가 증가한다. 관련: FR-007, FR-011
- TC-008 시설 설치 시 점수가 증가하고 필드에 시설이 생성된다. 관련: FR-008, FR-011
- TC-009 PVP OFF일 때 플레이어 공격이 적용되지 않는다. 관련: FR-011
- TC-010 시간이 종료되면 ended 상태와 랭킹이 표시된다. 관련: FR-012

## 현재 자동 검증
