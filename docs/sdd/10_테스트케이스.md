# 10 테스트 케이스

## 1. 기본 플로우

| ID | 테스트 | 관련 요구사항 |
| --- | --- | --- |
| TC-001 | 새 방 생성 시 방 코드와 플레이어 ID를 받는다. | FR-001 |
| TC-002 | 아바타 선택 후 입장하면 스냅샷에 `avatarId`가 포함된다. | FR-002 |
| TC-003 | 아바타를 바꿔도 체력, 속도, 공격력, 장비 성장 규칙은 동일하다. | FR-003 |
| TC-004 | 모든 플레이어가 Ready이면 countdown으로 전환된다. | FR-005 |
| TC-005 | countdown 종료 후 playing으로 전환되고 플레이어가 스폰된다. | FR-005 |

## 2. 조작/전투

| ID | 테스트 | 관련 요구사항 |
| --- | --- | --- |
| TC-006 | WASD 입력으로 플레이어 위치가 변경된다. | FR-006 |
| TC-007 | Space 입력 시 가까운 좀비에게 근접 공격이 적용된다. | FR-007, FR-008 |
| TC-008 | 가까운 좀비가 없으면 가장 가까운 좀비 방향으로 원거리 공격이 적용된다. | FR-007, FR-008 |
| TC-009 | 좀비 처치 시 점수와 킬 수가 증가한다. | FR-014 |
| TC-010 | 제한 시간 안에 연속 처치하면 콤보가 증가한다. | FR-014 |

## 3. 자원/성장/시설

| ID | 테스트 | 관련 요구사항 |
| --- | --- | --- |
| TC-011 | 자원을 획득하면 인벤토리 수량이 증가한다. | FR-009 |
| TC-012 | 자원 획득으로 자동 장비 레벨이 오른다. | FR-010 |
| TC-013 | 자원이 충분하면 시설을 설치할 수 있다. | FR-011 |
| TC-014 | 자원이 부족하면 시설 설치가 비활성화되거나 무시된다. | FR-011 |

## 4. 결과/랭킹

| ID | 테스트 | 관련 요구사항 |
| --- | --- | --- |
| TC-015 | 제한 시간 종료 시 결과 화면으로 전환된다. | FR-015 |
| TC-016 | 전원 사망 시 결과 화면으로 전환된다. | FR-015 |
| TC-017 | 결과 화면은 개인 점수 순으로 랭킹을 표시한다. | FR-016 |
| TC-018 | 팀 승패 또는 협동 보너스가 표시되지 않는다. | FR-016 |

## 5. 디자인/문구

| ID | 테스트 | 관련 요구사항 |
| --- | --- | --- |
| TC-019 | 아바타 선택 화면에 역할군, 직업, 능력치 문구가 없다. | NFR-005 |
| TC-020 | 로비에 팀 조합 또는 역할 분담 안내가 없다. | NFR-006 |
| TC-021 | HUD는 개인 HP, 점수, 자원, 장비, 콤보를 우선 표시한다. | NFR-006 |

## 6. 수동 확인 항목

- 데스크톱 브라우저에서 방 생성, Ready, 게임 HUD 진입 확인
- 모바일 뷰에서 조이스틱과 공격 버튼 확인
- 아바타별 시각 차이가 취향 선택으로 보이는지 확인
- 협동 설명 없이도 게임 목표가 이해되는지 확인
- 가만히 있는 플레이어가 제한시간 전체를 안정적으로 버티지 못하는지 확인
