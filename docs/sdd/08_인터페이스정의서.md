# 08 인터페이스 정의서

## 1. Client -> Server

### joinRoom

입장 또는 방 생성을 요청한다.

필드:
- `nickname: string`
- `roomId?: string`
- `avatarId?: number`
- `settings?: RoomSettings`

정책:
- `avatarId`는 외형 선택값이다.
- 서버는 `avatarId`를 저장하고 스냅샷에 포함한다.
- 서버는 `avatarId`에 따른 능력 차이를 적용하지 않는다.

### setReady

Ready 상태를 변경한다.

### updateSettings

방장 설정을 변경한다.

### input

이동, 공격, 시설 설치 입력을 전송한다.

### leaveRoom

룸 퇴장을 요청한다.

## 2. Server -> Client

### joined

입장 성공 결과를 반환한다.

필드:
- `roomId`
- `playerId`

### snapshot

표시 가능한 전체 게임 상태를 반환한다.

### errorMessage

입장 실패, 진행 중 입장 불가 등 오류 메시지를 반환한다.

## 3. GameSnapshot.players[] 주요 필드

- `id`
- `nickname`
- `avatarId`
- `position`
- `hp`
- `alive`
- `score`
- `kills`
- `combo`
- `inventory`
- `equipmentLevels`

## 4. 인터페이스 원칙

- 팀 단위 결과 필드는 정의하지 않는다.
- 역할군 ID, 직업 ID, 클래스 ID는 정의하지 않는다.
- 아바타는 외형 ID로만 취급한다.
