# 08 인터페이스 정의서

## Socket.IO Client -> Server
- `joinRoom(payload)`
  - `roomId?: string`
  - `nickname: string`
  - `settings?: RoomSettings`
- `setReady(ready)`
- `updateSettings(settings)`
- `input(input)`
  - 이동 벡터
  - 조준 벡터
  - 사격 여부
  - 근접 공격 여부
  - 설치할 시설 타입
- `leaveRoom()`

## Socket.IO Server -> Client
- `joined(payload)`
  - `roomId`
  - `playerId`
- `snapshot(snapshot)`
  - 룸의 표시 가능한 전체 게임 상태
- `errorMessage(message)`

## HTTP
- `GET /`: 프로덕션 빌드된 React 앱 반환
- `/socket.io`: Socket.IO 통신 엔드포인트
