# 08 인터페이스 정의서

## 1. HTTP API

### GET `/api/health`

서버 상태 확인용 API이다.

응답 필드:

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `ok` | boolean | 서버 정상 여부 |
| `rooms` | number | 현재 메모리에 존재하는 방 수 |
| `players` | number | 전체 접속 플레이어 수 |
| `uptimeSec` | number | 프로세스 업타임 |

### GET `/api/rooms`

현재 방 목록을 반환한다.

주요 응답 필드:

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `roomId` | string | 방 코드 |
| `roomTitle` | string | 방 제목 |
| `phase` | GamePhase | 방 상태 |
| `playerCount` | number | 현재 인원 |
| `maxPlayers` | number | 최대 인원 |
| `readyCount` | number | Ready 인원 |
| `gameMode` | GameMode | 게임 모드 |
| `difficulty` | GameDifficulty | 난이도 |
| `hostNickname` | string | 호스트 닉네임 |

## 2. Socket.IO 서버 이벤트

클라이언트가 서버로 보내는 이벤트이다.

| 이벤트 | payload | 설명 |
| --- | --- | --- |
| `joinRoom` | `JoinRoomPayload` | 방 생성 또는 입장 |
| `requestRoomList` | optional callback | 방 목록 요청 |
| `setReady` | boolean | Ready 상태 변경 |
| `updateSettings` | `RoomSettings` | 호스트의 방 설정 변경 |
| `chooseUpgrade` | string | 레벨업 선택지 선택 |
| `pauseGame` | boolean | 호스트의 일시정지/재개 |
| `restartGame` | none | 종료 후 재시작 |
| `input` | `PlayerInput` | 이동, 조준, 공격, 사용, 제작 입력 |
| `leaveRoom` | none | 방 나가기 |

## 3. Socket.IO 클라이언트 이벤트

서버가 클라이언트로 보내는 이벤트이다.

| 이벤트 | payload | 설명 |
| --- | --- | --- |
| `joined` | `{ roomId, playerId }` | 입장 성공 |
| `snapshot` | `GameSnapshot` | 게임 상태 전체 스냅샷 |
| `roomList` | `RoomSummary[]` | 방 목록 |
| `errorMessage` | string | 사용자 표시용 오류 메시지 |

## 4. 주요 타입

```ts
type GamePhase = 'lobby' | 'countdown' | 'playing' | 'paused' | 'ended';
type GameMode = 'timedSurvival' | 'endless' | 'killTarget' | 'supplyDefense';
type GameDifficulty = 'easy' | 'normal' | 'hard';
type ZombieType = 'normal' | 'runner' | 'tanker';
```

`GameSnapshot`은 방 정보, 플레이어, 좀비, 자원, 제작 스테이션, 시설, 투사체, 벽, 피드백 이벤트, 웨이브, 주야간 상태, 목표 상태, 맵 정보를 포함한다.

`PlayerInput`은 다음 입력을 포함한다.

- 이동 벡터와 조준 벡터
- 공격/근접 공격 플래그
- 아이템 사용 요청과 request id
- 시설 설치 요청
- 무기/보조장비 제작 및 장착 요청
- 보조장비 활성화 요청

## 5. URL 인터페이스

- `?room={ROOM_ID}`: 초대 링크로 특정 방 입장 플로우를 연다.
- `?concept=1`: 콘셉트 아트 보드 화면으로 진입한다.

## 6. 제약

- Socket payload는 TypeScript 타입으로 공유되지만 런타임 스키마 검증은 제한적이다.
- 운영 환경에서는 CORS 허용 범위와 입력 검증을 강화해야 한다.
