# 06 화면 설계서

## 로비 화면
- 닉네임 입력
- 방 코드 입력
- 방 생성/입장 버튼
- 플레이어 목록
- Ready 상태
- 방장 설정: 최대 인원, 게임 시간, PVP

## 게임 화면
- Canvas 전체 화면
- HUD: 체력, 점수, 보유 자원, 남은 시간, 웨이브, PVP 상태
- 미니 랭킹
- 시설 선택/설치 버튼
- 모바일: 좌측 이동 영역, 우측 공격 영역
- 플레이어/좀비는 스마트오피스 생존 톤의 2D 스프라이트로 표시한다.

## 결과 화면
- 점수 순위
- 닉네임
- 총점
- 좀비 처치 수
- 생존 시간

## 구현 위치
- 화면 컴포넌트: `client/src/main.tsx`
- 스타일: `client/src/styles.css`
