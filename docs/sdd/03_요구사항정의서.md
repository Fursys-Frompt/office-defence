## 2. 비기능 요구사항

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| NFR-001 | 서버 권위 상태를 기준으로 게임 결과가 결정되어야 한다. | P0 |
| NFR-002 | 클라이언트는 20Hz 스냅샷 기반으로 부드럽게 렌더링되어야 한다. | P0 |
| NFR-003 | 데스크톱과 모바일에서 모두 조작 가능해야 한다. | P0 |
| NFR-004 | 신규 사용자가 첫 화면에서 목표를 즉시 이해할 수 있어야 한다. | P0 |
| NFR-005 | 캐릭터 선택은 취향 만족을 주되 밸런스 문제를 만들지 않아야 한다. | P0 |
| NFR-006 | 협동 설명 없이도 게임 흐름이 성립해야 한다. | P0 |

## 3. 디자인 요구사항

- 캐릭터는 역할군이 아니라 스타일 선택지다.
- 캐릭터별 외형 차이는 취향, 분위기, 개성 표현에 집중한다.
- 캐릭터별 능력, 전투 방식, 성장 루트 차이는 제공하지 않는다.
- 아이템과 시설은 사무실 생존 콘셉트를 강화해야 한다.
- UI 문구는 협동, 팀워크, 역할 분담을 핵심 가치처럼 표현하지 않는다.

## 4. 제외 요구사항

- 협동 전용 미션
- 팀 보너스
- 직업/역할 기반 캐릭터
- 캐릭터별 고유 능력
- 팀 승리 조건
- 파티 조합 최적화

## 5. 제작대/무기 제작 미확정 항목

- 1차 구현 대상은 확정됐지만 수치는 초기 밸런스 값으로 관리하며 플레이 테스트 후 조정할 수 있다.
- 제작대 UI의 상세 레이아웃은 미정이다.
