## 3. UX 요구사항

- 첫 화면은 방 생성/입장과 튜토리얼 진입이 명확해야 한다.
- 방 목록은 현재 모드, 인원, 호스트 정보를 스캔 가능하게 보여줘야 한다.
- 아바타 선택은 외형 선택으로만 작동해야 하며 밸런스 차이를 만들지 않아야 한다.
- 제작과 장비 강화는 재료 부족 여부를 즉시 알 수 있어야 한다.
- 모바일 사용자는 조이스틱 위치를 좌/우로 바꿀 수 있어야 한다.
- 결과 공유는 게임 종료 직후 자연스럽게 접근 가능해야 한다.

## 4. 우선 보완 요구사항

- 깨진 한글 라벨과 문서를 UTF-8 기준으로 복구한다.
- `server/src/index.ts`의 룸, 전투, 제작, 스폰, 목표 판정을 모듈로 분리한다.
- shared 규칙 함수와 서버 종료 조건에 대한 자동화 테스트를 추가한다.
- PVP 플래그의 실제 동작 범위를 명확히 하거나 UI에서 제거한다.
- 메모리 기반 룸 상태의 운영 한계와 만료 정책을 정한다.
