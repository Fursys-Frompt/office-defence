# 03 요구사항 정의서

## 기능 요구사항
- FR-001 플레이어는 닉네임으로 방을 생성하거나 입장할 수 있다.
- FR-002 방장은 최대 인원, 게임 시간, PVP ON/OFF를 설정할 수 있다.
- FR-003 모든 플레이어가 Ready 상태가 되면 3초 카운트다운 후 게임이 시작된다.
- FR-004 플레이어는 WASD 또는 모바일 조이스틱으로 이동할 수 있다.
- FR-005 플레이어는 Space로 상황별 자동 공격을 사용할 수 있다. 가까운 적은 근접 공격, 먼 적은 자동 조준 원거리 공격으로 처리한다.
- FR-006 모바일은 자동 조준/공격 버튼 중심으로 조작한다.
- FR-007 맵에는 의자 부품, 책상 부품, 파티션 자재, 전력 모듈, 응급 키트가 생성된다.
- FR-008 플레이어는 자원으로 파티션 바리케이드, 책상 바리케이드, 응급 보급함, 전력 증폭기를 설치할 수 있다.
- FR-009 좀비는 가장 가까운 생존 플레이어를 추적한다.
- FR-010 30초마다 웨이브가 상승한다.
- FR-011 점수는 생존 시간, 좀비 처치, 자원 수집, 시설 설치, PVP 처치, 최후 생존으로 계산한다.
- FR-012 게임 종료 후 점수순 랭킹을 표시한다.

## 비기능 요구사항
- NFR-001 서버는 권위 상태를 유지하고 클라이언트는 입력만 전송한다.
- NFR-002 MVP 목표 틱레이트는 20Hz로 한다.
- NFR-003 DB 없이 서버 메모리만 사용한다.
- NFR-004 Render 단일 Web Service로 배포 가능해야 한다.
- NFR-005 데스크탑과 모바일 화면에서 주요 HUD가 겹치지 않아야 한다.

## 우선순위
- P0: 룸, Ready, 게임 루프, 이동, 공격, 좀비, 점수, 결과
- P1: 자원, 시설, 모바일 조작, Render 배포
- P2: 맵 연출, 고급 AI, 밸런싱 도구
