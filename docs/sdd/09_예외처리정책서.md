# 09 예외 처리 정책서

## 입장 예외
- 진행 중인 방 입장 시 `errorMessage` 전송
- 정원 초과 시 `errorMessage` 전송
- 닉네임 공백 시 `Survivor`로 대체

## 게임 예외
- 사망 플레이어 입력은 무시한다.
- 벽/시설과 충돌하는 이동은 적용하지 않는다.
- 자원이 부족한 시설 설치는 무시한다.
- 방장 외 설정 변경 요청은 무시한다.

## 연결 예외
- 플레이어 연결 해제 시 룸에서 제거한다.
- 방에 남은 인원이 없으면 룸을 삭제한다.
- 방장이 나가면 남은 첫 플레이어가 방장이 된다.

## 운영 로그
- MVP는 서버 콘솔 로그만 사용한다.
- 파일 로그/외부 모니터링 연동은 MVP 이후 결정한다.
