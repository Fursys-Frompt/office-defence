# 09 예외 처리 정책서

## 1. 입장 예외

- 방 정원이 가득 차면 `errorMessage`를 전송한다.
- 진행 중인 방 입장 시 `errorMessage`를 전송한다.
- 잘못된 방 코드 입력 시 `errorMessage`를 전송한다.

## 2. 입력 예외

- 사망 플레이어 입력은 무시한다.
- 잘못된 시설 타입 요청은 무시한다.
- 자원이 부족한 시설 설치 요청은 무시한다.
- 방장 외 설정 변경 요청은 무시한다.

## 3. 연결 예외

- 플레이어 연결 해제 시 룸에서 제거한다.
- 방에 남은 인원이 없으면 룸을 삭제한다.
- 방장이 나가면 남은 첫 플레이어가 방장이 된다.

## 4. 아바타 예외

- 범위를 벗어난 `avatarId`는 안전한 기본값으로 보정한다.
- 아바타 로딩 실패 시 기본 플레이어 표시로 대체한다.
- 아바타 선택 실패가 게임 능력이나 밸런스에 영향을 주면 안 된다.

## 5. 정책 원칙

예외 처리는 개인 세션 안정성을 우선한다. 협동 상태 복구, 팀 재배치, 역할 대체 같은 처리는 현재 제품 범위에 포함하지 않는다.
