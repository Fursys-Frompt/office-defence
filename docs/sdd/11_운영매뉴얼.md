# 11 운영 매뉴얼

## 1. 실행

```bash
npm install
npm run dev
```

## 2. 검증

```bash
npm run typecheck
npm run build
```

## 3. 운영 확인 절차

1. 브라우저에서 `http://localhost:5173`에 접속한다.
2. 닉네임을 입력한다.
3. 취향 아바타를 선택한다.
4. 방을 생성한다.
5. Ready를 누른다.
6. 게임 화면에서 이동, 공격, 수집, 시설 설치를 확인한다.
7. 결과 화면에서 개인 랭킹이 표시되는지 확인한다.

## 4. 디자인 확인 절차

- 아바타 선택이 역할 선택처럼 보이지 않는지 확인한다.
- 아바타 설명에 능력, 직업, 팀 기여 문구가 없는지 확인한다.
- 게임 HUD가 개인 점수와 생존 판단을 중심으로 구성되어 있는지 확인한다.
- 결과 화면이 팀 승패가 아니라 개인 랭킹으로 읽히는지 확인한다.

## 5. 운영 주의사항

- 현재 DB가 없으므로 서버 재시작 시 모든 방과 게임 상태가 사라진다.
- 룸 상태는 메모리 기반이다.
- 멀티 접속은 가능하지만 제품 설명에서 협동을 핵심으로 홍보하지 않는다.
- 캐릭터별 능력 차이가 있는 것처럼 안내하지 않는다.

## 6. QA 관점

- 초반 10초 안에 신규 플레이어가 목표를 이해하는지 확인한다.
- 콤보 HUD가 보상감을 주는지 확인한다.
- 자원 수집과 제작대 무기/보조장비 성장의 연결이 체감되는지 확인한다.
- 웨이브가 진행될수록 생존 압박이 커지는지 확인한다.
