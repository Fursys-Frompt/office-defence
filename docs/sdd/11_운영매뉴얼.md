# 11 운영 매뉴얼

## 설치
```bash
npm install
```

## 개발 실행
```bash
npm run dev
```
- 클라이언트: http://localhost:5173
- 서버: http://localhost:3000

## 타입 체크
```bash
npm run typecheck
```

## 프로덕션 빌드
```bash
npm run build
```

## 프로덕션 실행
```bash
npm start
```
- 접속: http://localhost:3000

## Render 배포
1. GitHub 저장소에 프로젝트를 push한다.
2. Render에서 New Web Service를 생성한다.
3. 저장소를 연결한다.
4. Build Command: `npm ci && npm run build`
5. Start Command: `npm start`
6. Node 버전은 20 이상으로 설정한다.
7. `render.yaml`을 사용할 경우 Render Blueprint로 배포할 수 있다.

## 운영 주의
- DB가 없으므로 서버 재시작 시 모든 방과 게임 상태가 사라진다.
- 무료 플랜 sleep 이후 최초 접속 지연이 발생할 수 있다.
- 동시 접속 한계는 Render 플랜과 서버 틱 부하에 따라 별도 부하 테스트가 필요하다.
